# My Skills

科研与开发中使用的个人 AI Skills。每个 skill 都是一份独立的 Markdown 文件，按需下载并交给 AI 使用。

[在线浏览 Skills](https://fduhcshi.github.io/my_skill/)

## Skills

| Skill | 简介 |
| --- | --- |
| [Paper Reading · 深度读论文](./paper-reading.md) | 深入解读论文的问题、公式、方法、理论与实验，整理为中文学习笔记。 |
| [Paper Experiment Detail · 算法与实验复现](./paper-exp-detail.md) | 梳理算法流程和实验配置，给出不同算力预算下的复现方案。 |
| [Idea Insight · 研究想法成稿](./idea-insight.md) | 将零散想法发展为包含问题定义、方法框架、理论思路和实验设计的研究草稿。 |
| [Python Project Standards · Python 项目规范](./python-project-standards.md) | 规范 Python 项目的模块组织、接口、YAML 配置与运行方式。 |
| [Research to Markdown · 整理研究记录](./research-to-markdown.md) | 将代码、配置、日志和实验结果整理为带生成时间的研究文档与数据索引，开篇速览突出本次实验与主要结果。 |
| [Markdown to Interactive HTML · 交互展示研究](./markdown-to-interactive-html.md) | 将 Markdown 报告与关联数据转换为离线可用的交互网页。 |
| [Sticker Neo-Brutalism · 贴纸风网页设计](./sticker-neo-brutalism.md) | 使用奶油底色、粉彩卡片、粗边框和硬阴影设计网页。 |

`research-to-markdown` 新报告默认按生成时刻命名为 `report_YYYYMMDD_HHMMSS.md`，例如 `report_20261021_152048.md`。用户指定文件名优先；更新旧报告时沿用原文件名，新建报告重名则加序号，避免覆盖。标题后的“本次实验速览”先说明本次做了什么、主要结果和关键限制，读完即可掌握重点，后文保留详细分析与证据。

> 请使用 `research-to-markdown`，根据这个项目的代码、配置、运行日志与结果整理研究报告，按生成时刻使用默认文件名。标题后先写“本次实验速览”，突出本次实验或变化、主要结果、关键限制与判断，再展开详细分析，注明证据来源并建立数据资产索引。
